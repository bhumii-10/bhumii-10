## Featured Project

### AI Resume Checker

A full-stack AI-powered resume analysis platform developed independently to help users evaluate and improve their resumes.

**Key Features**

* AI-powered resume analysis and feedback
* Resume upload and processing
* Automated identification of resume strengths and improvement areas
* Actionable recommendations for improving resume quality
* Responsive and modern user interface
* RESTful backend APIs
* MongoDB-based data management
* Production deployment

**Tech Stack:** React.js, Node.js, Express.js, MongoDB, AI APIs, Tailwind CSS, Vite
